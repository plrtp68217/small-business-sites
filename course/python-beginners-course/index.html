Программа курса

Модуль 1. Введение и среда разработки ≈ 3-4 дня
Установка Python, настройка IDE, первые строки кода, работа с терминалом.
→ Навык: Уверенная работа в PyCharm / VS Code, базовые команды терминала
Модуль 2. Основы синтаксиса: данные и логика ≈ 5-6 дней
Переменные, типы данных, условные операторы, циклы, базовые структуры.
→ Навык: Писать чистые условия и циклы, анализировать алгоритмы
Модуль 3. Коллекции и функции ≈ 5 дней
Списки, словари, кортежи, функции, аргументы, область видимости.
→ Навык: Работа с данными, создание переиспользуемых функций
Модуль 4. Файлы и исключения ≈ 4 дня
Чтение/запись файлов, обработка ошибок, менеджеры контекста.
→ Навык: Автоматизация обработки данных из файлов, устойчивый код
Модуль 5. Парсинг и библиотеки Requests/BS4 ≈ 6 дней
HTTP-запросы, BeautifulSoup, сбор данных с сайтов.
→ Навык: Создание парсера новостей / товаров (портфолио)
Модуль 6. Объектно-ориентированное программирование ≈ 7 дней
Классы, объекты, наследование, инкапсуляция, магические методы.
→ Навык: Проектирование архитектуры приложений на ООП
Модуль 7. Базы данных SQLite + API ≈ 6 дней
SQL-запросы, интеграция с API, получение и сохранение данных.
→ Навык: Работа с реальными API и проектирование БД
Модуль 8. Финальный проект: Telegram-бот + парсер портфолио / ключевой результат ≈ 10-12 дней
Объединение модулей: бот анализирует цены, присылает отчёт, используется база данных.
→ Навык: Полноценный продукт для резюме, код-ревью от наставника
